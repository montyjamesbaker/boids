<h1>Boids</h1>

<h2>Description</h2>
A 3D Boid simulation using basic steering and flocking behaviour AI.<br><br>
Individual agents use Cohesion, Seperation and Alignment behaviours to interact with other nearby agents, simulating bird-like flocking behaviour.<br><br>
<img width="800" height="374" alt="BoidsInMotion" src="https://github.com/user-attachments/assets/29ab0daa-5d5e-4e3f-82dc-905b8b3cd2a8" /><br>
Fields on the GUI allow the user to alter the weights of these behaviours and boundaries, such as area they are confined to and the distance between boids before they consider themselves near to other agents.<br><br>
Additional unimplemented behaviours such as Pursue and Evade allow agents to chase and evade other agents based on their position and velocity, predicting where they're going to be.<br>




<h2>Languages and Utilities Used</h2>
- <b>Unreal Engine 5.3</b><br>
